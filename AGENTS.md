# Codex Project Shim

The authoritative repository instructions live in [`.agents/AGENTS.md`](.agents/AGENTS.md). Read and follow that file before making substantive changes.

If this file and `.agents/AGENTS.md` conflict, `.agents/AGENTS.md` is the source of truth for repository policy, workflow, versioning, changelog maintenance, validation, and release conventions.

Repository skills live under `skills/`. When a task matches one of them, read that skill's `SKILL.md` and follow its workflow in addition to the canonical repository policy.
