I don't think we should extend library hours this winter while the side ramp remains inaccessible. Last January's count recorded 14 evening visits per night. Those visits matter, and later hours could help shift workers who struggle to get there during the day. But the current proposal would staff only one entrance and add no security funding. Before we ask library staff to cover longer evenings, we ought to fund the support those hours require. Meanwhile, the same budget could repair the side ramp, addressing an access problem we already know exists. My priority is making the library easier to enter before keeping it open longer. I'd put this winter's money into the ramp and ask for a future hours proposal that includes adequate staffing and security. A useful library needs both welcoming hours and a usable way through the door.
