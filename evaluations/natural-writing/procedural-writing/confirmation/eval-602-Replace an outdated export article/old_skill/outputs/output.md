# Export monthly records

Exports use the account shown in the **top-right account label**. Other open tabs and saved sign-ins do not affect which account is exported.

## Start or resume an export

1. Check the account label. If you are unsure which account to use, ask your lead before exporting.
2. Open **Exports > Recent** and look for an existing queued or running job for the account and month you need. Resume that job from Recent instead of submitting it again.
3. If you need a new job, open **Records**, select the **Month**, and click **Export**.
4. Open the job in **Exports > Recent**. Check its **Account** and **Month** fields to confirm what is being exported.
5. Wait until **Status = Complete**, then click the job’s **Download package** button.

You can close the browser while the job runs. Return to **Exports > Recent** later to check the same job and download its package.

## Save the package and attachments

Save the package in the shared folder **Monthly review**, in a subfolder named for the selected month.

The package contains record text and attachment filenames, but it does **not** contain the attachment files. Save those files separately in the same month’s subfolder if you need them later.
