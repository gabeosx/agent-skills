# Set up your Plover Room sensor

1. Plug the sensor into a wall outlet using the supplied cable. Its light normally turns blue within 20 seconds.
2. In the Plover app, open **Rooms** and choose the room where you want the sensor.
3. Tap **Add sensor**, then scan the square code on the back of the sensor.
4. When the sensor’s name appears in that room, tap **Run sample**.
5. Open that room’s **Activity** screen. Check that the sample shows **Result = Received** and **Samples = 1**. The sensor is then ready for ordinary use.

## Only if you run into a problem

- **Light still dark after 20 seconds:** Reseat both cable ends and try another wall outlet.
- **“Already paired” when scanning:** Hold the recessed **Pair** button for six seconds until the light flashes blue, then scan again. This removes the old pairing.
- **Sensor appears in the wrong room:** Open that sensor’s menu and choose **Move to room**.
- **“Sensor offline” when running a sample:** Move the sensor closer to the room’s hub and run the sample again. Check the room’s **Activity** screen for **Result = Received** and **Samples = 1**.

A normally connecting new sensor does not need a reset. Use the supplied cable; replace it only if it is visibly damaged.
