# Send tonight’s Evening East manifest

1. Open **Shipments**, select **Evening East** (24 shipments), and click **Send manifest**.
2. In the send dialog, set **Destination** to **East review** and click **Send**.
3. Open **Review desk > East review > Incoming**. Find the row named **Evening East** and check that it shows **Status = Ready** and **Shipments = 24**. These are the checks for the receiving team’s copy. The green **Request accepted** toast only confirms that the request entered the queue.

If the row shows **Status = Destination paused**, open **Review desk > East review > Settings** and switch **Receiving** from **Paused** to **Active**. Return to **Shipments** and send **Evening East** again with **Destination = East review**. This replaces the pending copy without creating a duplicate. Return to **Incoming** and repeat the row checks above.

Other failed statuses have no documented operator remedy. If the row is missing or its name or shipment count does not match, the supplied instructions do not establish a remedy or confirm delivery.
