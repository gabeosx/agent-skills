1. Open **Items > select item > Receive existing stock**.
2. Enter the quantity and cost in the item's stock unit. For Flour, the stock unit is grams: a 6 kg sack contains **6,000 g**. If the sack costs $72, enter **6000** in **Quantity** and **0.012** in **Cost (per stock unit)** ($72 ÷ 6,000 g). There is no cost-unit selector; both entries must use grams.
3. Check both fields before selecting **Post**. A blank cost is stored as zero. Correct either field directly if needed.
4. Select **Post** when the entries are correct. You can view the posted quantity, stock unit, unit cost and receipt ID in **Items > select item > History**.

Posted receipts cannot be edited or undone. If a posted receipt is wrong, give its receipt ID to the inventory lead for an audited correction.
