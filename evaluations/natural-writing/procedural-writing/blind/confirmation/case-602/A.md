# Export monthly records from Cove Ledger

## Start or resume an export

Exports use the account shown in the **top-right account label**. Check that label before exporting; other tabs and saved sign-ins do not affect the export account. If you are unsure which account you used, ask your lead.

1. Open **Exports > Recent** and look for an existing queued or running job for the account and month you need. Its **Account** and **Month** fields identify the export. If one exists, resume it from **Recent** rather than submitting another export.
2. If you need to start a new export, open **Records**, select the month with **Month**, and press **Export**.
3. Open the job in **Exports > Recent**. Check its **Account** and **Month** fields against the account and month you intended to export.
4. Wait for **Status = Complete**. Queued jobs may take a while. You can close the browser and return to **Exports > Recent** later; closing it does not stop the job. Continue with the existing job rather than starting again because a download has not arrived.
5. When the job is **Complete**, click its **Download package** button.

## Save the package and attachments

The package contains record text and attachment filenames. It **does not contain the attachment files**, so it is not a complete archive. Save the attachment files separately if you need them later.

Place the downloaded package and any separately saved attachments in the shared folder **Monthly review**, in a subfolder named for the selected month, so the monthly review team can find them.
