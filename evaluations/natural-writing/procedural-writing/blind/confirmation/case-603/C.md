# Set up your Plover Room sensor

1. Plug the sensor into a wall outlet using the supplied cable. Its light normally turns blue within **20 seconds**.
2. In the Plover app, open **Rooms**, choose the intended room, and tap **Add sensor**.
3. Scan the square code on the back of the sensor.
4. When the sensor’s name appears in that room, tap **Run sample**.
5. Open that room’s **Activity** screen. A successful sample shows **Result = Received** and **Samples = 1**. The sensor is then ready for ordinary use.

## If something goes wrong

- **Light still dark after 20 seconds:** Reseat both cable ends and try another wall outlet. The supplied cable is sufficient; replace it only if it is visibly damaged.
- **“Already paired” when scanning:** Hold the recessed **Pair** button for **six seconds**, until the light flashes blue, then scan again. This removes an old pairing. A normally connecting new sensor does not need a reset.
- **Sensor in the wrong room:** Open that sensor’s menu and choose **Move to room**.
- **“Sensor offline” after Run sample:** Move the sensor closer to the room’s hub and run the sample again. Check Activity for **Result = Received** and **Samples = 1**.
