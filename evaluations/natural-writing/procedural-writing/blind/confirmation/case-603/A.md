# Set up a Plover Room sensor

1. Plug the sensor into a wall outlet using the supplied cable. The light normally turns blue within 20 seconds.
2. In the Plover app, open **Rooms**, choose the intended room, and tap **Add sensor**. Scan the square code on the sensor’s back.
3. When the sensor’s name appears in that room, tap **Run sample**.
4. Open that room’s **Activity** screen. A successful sample shows **Result = Received** and **Samples = 1**. The sensor is then ready for ordinary use.

## If something goes wrong

- **Light still dark after 20 seconds:** Reseat both cable ends and try another wall outlet.
- **Scanning shows “Already paired”:** Hold the recessed **Pair** button for six seconds until the light flashes blue, then scan again. This removes an old pairing.
- **Sensor appears in the wrong room:** Open that sensor’s menu and choose **Move to room**.
- **Run sample shows “Sensor offline”:** Move the sensor closer to the room’s hub and run the sample again.

A normally connecting new sensor does not need a reset. The supplied cable is sufficient; replace it only if it is visibly damaged.
