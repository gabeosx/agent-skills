Connect your shop to Larch

1. Open Connections > Add shop and authorize the shop you want to connect, then select Import products.
2. Open Connections > Products and review Mapping status for every row:
   - **Mapped:** The row is ready. Leave its mapping as it is.
   - **Unmatched:** Select Link item and choose the corresponding inventory item. If that item does not exist, ask the inventory lead to create it before linking the row.
3. After all rows are mapped, press Start sync. Importing products alone does not start order sync.

If Connections > Account shows the wrong shop, select Disconnect, authorize the correct shop, then reimport products. Review Mapping status again before starting sync.

If sync status is **Authorization expired**, select Reauthorize. Reauthorization is only needed for that status.
