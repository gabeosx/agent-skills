# Receive existing stock

1. Go to **Items**, select the item, and choose **Receive existing stock**.
2. Enter **Quantity** in the item's stock unit and **Cost (per stock unit)** as the cost of one of those units. For Flour, the stock unit is grams: a 6 kg sack costing $72 means **Quantity: 6000** and **Cost (per stock unit): $0.012** ($72 ÷ 6000). There is no cost-unit selector.
3. Check both fields before selecting **Post**. Blank cost is stored as zero. Correct either field directly if needed.
4. Select **Post** when the quantity and unit cost are correct.

To check the posted receipt, go to **Items > select item > History**. The row shows the quantity, stock unit, unit cost, and receipt ID.

Posted receipts cannot be edited or undone. If you find an error, give the receipt ID to the inventory lead for an audited correction.
