# Connect your shop to Larch

1. Open **Connections > Add shop** and authorize the shop you want to connect.
2. Select **Import products**.
3. Open **Connections > Products** and review each row's **Mapping status**:
   - **Mapped:** the row is ready. Leave its mapping unchanged.
   - **Unmatched:** select **Link item**, then select the corresponding inventory item. If that item does not exist, ask the inventory lead to create it before linking the row.
4. Once all rows are mapped, press **Start sync**. Importing products alone does not start order sync.

If **Connections > Account** shows the wrong shop, select **Disconnect**, authorize the correct shop, then reimport products. Review their mapping status before starting sync.

If sync status is **Authorization expired**, select **Reauthorize**. Reauthorization is only needed for that status.
