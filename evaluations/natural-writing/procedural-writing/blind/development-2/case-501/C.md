# Receive stock in Brindle

1. Open **Items > select item > Receive existing stock**.
2. Enter **Quantity** in the item's stock unit and **Cost (per stock unit)** as the cost of one of those units. For Flour, the stock unit is grams: a 6 kg sack is **6,000 g**, so enter **6000** for Quantity and **0.012** for Cost ($72 ÷ 6,000 g = $0.012 per gram). There is no cost-unit selector. A blank cost is stored as zero.
3. Before selecting **Post**, check that Quantity is **6000** and Cost is **0.012** for this sack. Correct either field directly if it differs. Posting cannot be edited or undone.
4. Select **Post**, then open **Items > select item > History**. Find the posted row and check its quantity, stock unit and unit cost against **6,000 g at $0.012 per gram**. If a posted value is wrong, give the row's receipt ID to the inventory lead for an audited correction.
