1. Open **Connections > Add shop** and authorize the desired shop.
2. Select **Import products**.
3. Open **Connections > Products** and review **Mapping status** for every row:
   - **Mapped:** the row is ready. Leave its mapping as it is.
   - **Unmatched:** select **Link item** and choose the corresponding inventory item. If it does not exist, ask the inventory lead to create it before linking that row.
4. Once all rows are mapped, press **Start sync**. Importing products alone does not start order sync.

If **Connections > Account** shows the wrong shop, select **Disconnect**, authorize the correct shop, then reimport products. Disconnect only to correct the wrong shop.

If sync status is **Authorization expired**, select **Reauthorize**. Reauthorization is needed only for that status.
