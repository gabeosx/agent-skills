I don't think we should extend library hours this winter while the side ramp remains inaccessible. Longer evenings could help shift workers, and that deserves consideration. But last January's count recorded 14 visits per night, which gives us a concrete basis for weighing the use of those hours against another need. Under the current proposal, only one entrance would be staffed, and there is no funding for additional security. I would want those limits addressed before asking the library to stay open later. The same budget could repair the side ramp, making an existing way into the building accessible. That is where I would put the money this winter. We can return to evening hours with a proposal that accounts for staffing and security; for now, repairing the ramp would address an access problem already in front of us.
