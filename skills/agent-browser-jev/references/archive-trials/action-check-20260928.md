## Retained mechanisms and historical lessons

Jev interprets meaning while code carries exact values, conditional arithmetic, observed order and browser mechanics. Action review and bounded unfinished-handoff review expose prerequisites and alternative routes without replacing the authorized action set. Exact whole-word goal spans may supply discovery queries; final text still requires caller values. Separate field/value-role judgments keep uncertain and multi-role aliases advisory. Native focus/Enter activation avoids demonstrated wrapped-link pointer misses. Choice and readback bounds recovered an observed provider size failure without a blanket request-size guarantee.

V8 action review regressed four tree/ordinal-search cases. Passing conditional code facts into review and distinguishing branch expansion repaired all four targeted cases on v9, which then passed 42/42 goals+reports on fresh 1043–1044. This is the useful lesson from older rigid controllers: retain factual calculations and navigation distinctions, not website/task sentence rules.

Two stronger historical target-scope controllers ran unchanged on the same four clean states used for v9: 2/4 official and scope-correct goals each, matching v9. Their earlier 6/8 or 5/8 scores belong to other cohorts. The previous scores remain preserved; they do not establish a universally better source.

Retain the simpler path because excerpts showed no verified recovery, not because their removal is proven to fix replies. Compact observations remain explicitly limited. Frozen v10/v11 source and tests retain the rejected experiment.

The runtime stop decision was recorded before the final WebArena intents/results in `runtime-iteration-stop.json`. More same-model semantic gates had ceased to provide repeatable gains.
