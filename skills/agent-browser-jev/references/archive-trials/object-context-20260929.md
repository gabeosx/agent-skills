The rejected argument-only invocation created no campaign and dispatched no model. A separate mistaken MiniWoB positive-control flag also failed before dispatch; corrected no-model smoke passed. Both logs are preserved.

Only synthetic login passed. Candidate reported complete; baseline handed off after reward. Supplied quoted fixture credentials do not establish production authentication support. Four tasks returned input_required while values already existed in the legitimate goal or page: flight airport/date values, a date, copying textarea content and extracting its last word. Geometry and calendar/food controls lacked usable gestures. Word extraction and contact pagination did not complete. Both slider arms exhausted 90 decisions.

The clearest next experiment is a general exact-value source binding, not another broad action veto. Jev would identify an explicitly authorized caller span or current observed text source and the destination; code would copy exact bounded content, bind it to the observation, revalidate freshness and retain operation authorization. Current goal-query binding explicitly permits discovery only, and table-copy support is narrow. Counterexamples must include missing content, swapped fields, page instructions, masked/readonly sources, stale changes, duplicate text, ambiguous source sets, formatting and no-submit goals. Word extraction needs its own explicit text/token semantics rather than silently treating arbitrary prose as a table. These capabilities are not implemented or claimed. The new-family sample is now historical evidence, not an untouched holdout for such a future change.

Planning, community/recipient binding, author-filtered discovery and full-set completion remain semantic limits. Repeating failed WebArena cases or adding more same-model vetoes is not justified by these results. Independent caller recovery also remains unmeasured; scripted recoveries only validate the continuation contract.
