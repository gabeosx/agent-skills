# RC improvement study

The final frozen v17 comparison supports a materially improved **1.3.0 release candidate** on this narrow Shopping Admin sample: **0/9 retained Jev → 3/9 candidate Jev**, with three paired wins, no losses and no standalone false completion. This clears the predeclared 25-percentage-point gain threshold. It does **not** establish statistical significance (exact paired two-sided p=0.25), full-WebArena superiority or unseen-family generalization. The separate current-Codex workflow reaches **6/9**, with extra reasoning and recovery. Its incomplete product-creation attempt has a confirmed shared-schema scope violation.

GPT-5.4 was a separately metered benchmark caller in earlier studies, not Jev's runtime. This campaign uses the current Codex session as caller and **makes no GPT-5.4 API calls**; Jev remains `typesafe/jev-1.13`. The WebArena study now defaults to the current agent, with explicit opt-in for legacy API callers. Current-agent reasoning, browser recovery and additional helper invocations are assistance; their subscription cost and tokens are unmeasured, not zero. Renewed-campaign OpenRouter spend reconciles to **$2.641157022**, including failed candidates and interrupted calls. Earlier studies below retain their own historical costs and outcomes.

## General repairs in the candidate

- Bounded accessibility settling at initial capture and after navigation or state-changing controls makes delayed form fields available within the task deadline.
- Large captures preserve noninteractive feedback instead of dropping it when compacting controls. Original references and ancestor context remain available in capture windows.
- Capture-local inspection history identifies already-read windows; this never establishes website coverage.
- Closed native dropdowns with large option inventories retain the form and current selections together, with every option available in separate inspection windows. Expanded and custom pickers retain their original structure.
- Named clickable generic controls retain their actual observed names.
- Explicitly selected later fields can resolve fresh goal values after speculative lookahead is exhausted; unrelated empty fields no longer necessarily block a verified completion.
- Exact numeric substrings and civil-calendar calculations bind values to the original goal and current field. Calendar calculations require an explicit caller date; they never use the wall clock as a hidden anchor.
- Completion review distinguishes the requested destination from a containing collection. Action review distinguishes a discovery query from the final selected item and object identity from the requested operation.
- Bounded class and ARIA hints from observed non-secret text fields reach Jev as evidence, without mapping class names to actions in code.

These changes use accessibility structure and widget state. They contain no benchmark IDs, expected answers, site-specific selectors or evaluator routes.

The [final frozen comparison and audit](#final-frozen-v17-comparison-and-audit) is the current acceptance evidence. The chronological development results below preserve rejected variants, regressions and failed attempts; they are not pooled into a current-candidate success rate.
