## Implementation boundary

Jev continues to interpret goals, relate them to observed objects and select actions. Code copies exact values, computes supported comparisons, preserves target identities and checks dispatch freshness. Scripted benchmark controls qualify the application/evaluator and never act as hidden plans in model-driven trials.

A useful handoff should name the remaining value, evidence or control boundary and preserve work already done. The caller can resolve that particular boundary and resume the original goal. Extra caller reasoning or gestures must remain assistance, even when Jev performs subsequent browser work. A safe unfinished return is valuable but does not increase autonomous completion.
